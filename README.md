Web Developer and Creative Project Lead based in India. I move between full-stack web engineering, AI/ML research, and whatever problem is interesting enough to pull me in. TypeScript by day, Jupyter notebooks at 2am — the range is real.

Next.js, Prisma, TypeScript, structured properly from day one: `components/`, `lib/`, `prisma/`, `store/` — everything has a place and a reason. 95%+ TypeScript. Not another Stripe tutorial dressed up as a project.

**[studio](https://github.com/K3RAE/studio)** — Next.js + Firebase Studio. TypeScript-heavy, Tailwind-configured, App Hosting deployment. Early stage but moving.

## What I've shipped

**[LAWGPT](https://github.com/K3RAE/LAWGPT)** — AI legal assistant in Python. Full RAG pipeline from scratch: document ingestion → chunking → vector DB → knowledge graph (`legal_graph.py`, `graph_rag.py`) → trained outcome classifier over a 500-entry legal dataset. The kind of project that required actually understanding how legal reasoning works before touching a single line of code.

**[ALZHEIMERS-EARLY-DETECTION](https://github.com/K3RAE/ALZHEIMERS-EARLY-DETECTION)** — Early Alzheimer's detection using multi-modal data fusion. Jupyter-based, deep in medical data processing and predictive ML. Research territory — the work that doesn't get deployed but changes what's possible.
